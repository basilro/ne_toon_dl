# ne_toon_dl

네이버웹툰 무료 회차 자동 다운로드 (SJVA / FlaskFarm 플러그인)

## 주요 기능

- **설정** — 쿠키 등록, 다운로드 경로, 폴더명 형식, 스케줄 주기, 알림 웹훅 설정
- **연재 목록** — 현재 연재중인 웹툰 전체 목록을 요일별로 보여주고, 원하는 작품을 체크해서 다운로드 스케줄에 바로 등록 (작품코드 수동 입력 불필요)
- **수동 다운로드** — 제목/URL/titleId 분석 후 받을 회차를 골라 즉시 다운로드
- **진행 상황** — 자동/수동 다운로드 실시간 진행률
- **다운로드 이력** — 작품·회차별 다운로드 상태 조회 및 정리
- 무료 회차만 자동 수집, 유료화 공지 감지, info.xml/cover.jpg 메타데이터 생성, ZIP 압축

## 폴더명 형식

작품 폴더와 회차 폴더의 이름을 설정 화면에서 정할 수 있습니다.
규칙은 하나입니다. 중괄호로 감싼 말만 값으로 바뀌고, 나머지 글자는 적은 그대로 쓰입니다.
자동 다운로드와 수동 다운로드가 같은 설정을 씁니다.

| 쓸 수 있는 말 | 바뀌는 값 |
| --- | --- |
| `{title}` | 작품명 |
| `{subtitle}` | 회차명 |
| `{no}` | 회차 번호 (자릿수는 별도 설정) |
| `{title_id}` | 네이버 작품 번호 |

기본값은 작품 `{title}`, 회차 `{no}_{subtitle}`, 회차 번호 자릿수 `4` 이고, 결과는
`전지적 독자 시점/0003_3화 - 시작/` 입니다. 회차 형식을 `[{no}] {subtitle}` 로 두면
`[0003] 3화 - 시작` 이 됩니다. 설정 화면의 예시 버튼을 누르면 입력란이 채워지고,
미리보기 버튼으로 실제 저장 경로를 확인할 수 있습니다.

- `{no:04d}` 같은 파이썬 서식은 적을 필요가 없습니다. 자릿수는 별도 설정으로 정하고,
  예전에 적어 둔 서식도 그대로 동작합니다.
- 회차 번호 자릿수를 `0` 으로 두면 채우지 않습니다(`0003` 대신 `3`).
- 파일명에 쓸 수 없는 문자(`\ / * ? : " < > |`)는 자동으로 `_` 로 바뀝니다.
- 모르는 말을 적으면 저장은 되지만 실제 다운로드는 기본값으로 처리하고 로그에 경고를 남깁니다.
- 형식을 바꿔도 이미 받아 둔 폴더의 이름은 바뀌지 않습니다. 새로 받는 회차부터 적용됩니다.
- ZIP 압축을 켜면 아카이브 이름도 회차 폴더명을 따릅니다. 형식을 바꾸기 전에 받아 둔
  `NNNN_` 이름의 아카이브도 기존 규칙으로 함께 인식해서 다시 받지 않습니다.
